# 🤖 Basic Chatbot

## 📌 Project Overview

This project is a simple rule-based chatbot developed in Python as part of the CodeAlpha Internship Program.

The chatbot interacts with users through predefined responses using conditional statements and loops.

---

## 🚀 Features

- Greets the user
- Answers basic questions
- Handles unknown inputs
- Exits gracefully on command
- Beginner-friendly Python project

---

## 🛠 Technologies Used

- Python 3
- VS Code

---

## 📚 Concepts Used

- Functions
- While Loops
- Conditional Statements (if-elif-else)
- User Input
- Output Formatting

---

## ▶️ How to Run

1. Clone the repository

```bash
git clone https://github.com/yourusername/CodeAlpha_Basic_Chatbot.git
```

2. Navigate to the project folder

```bash
cd CodeAlpha_Basic_Chatbot
```

3. Run the program

```bash
python chatbot.py
```
